# セキュリティベストプラクティス

このドキュメントは、プロジェクト全体で適用されるセキュリティのベストプラクティスを記載しています。

## 認証・認可

1. **最小権限の原則**: ユーザーには必要最小限の権限のみを付与
2. **サーバー側での検証**: クライアント側の認可チェックは必ずサーバー側でも実施
3. **トークンの適切な管理**: アクセストークンは安全に保存し、必要な場所でのみ使用

## 状態管理

1. **センシティブデータの最小化**: 必要以上にユーザー情報を保持しない
2. **適切なライフサイクル管理**: コンポーネントのマウント/アンマウント時に状態をクリア
3. **不変性の維持**: 状態の変更は常に新しいオブジェクトを作成して行う

## データ保護

1. **暗号化**: 機密情報は暗号化して保存・送信
2. **ログの適切な管理**: 個人情報をログに出力しない
3. **エラーメッセージの慎重な取り扱い**: エラーメッセージに機密情報を含めない

## コード品質・型安全性

1. **型安全なコード**: TypeScriptの型システムを最大限活用し、ランタイムエラーを防ぐ
2. **Lambda関数の型定義**: すべてのLambda関数レスポンスに適切な型を定義する（[Lambda型安全ガイドライン](../.claude/rules/lambda-type-safety.md)参照）
3. **any型の禁止**: `any` 型の使用を避け、具体的な型を指定する
